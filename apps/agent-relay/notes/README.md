# Agent Relay notes

**Utility:** locates application history, measurements and proposals.  
**Usage:** read to understand results and outstanding decisions.

## Records

- [Observations](observations/README.md): measured results awaiting operator validation.
- [Proposals](proposals/README.md): unarbitrated design candidates.
- [Follow-up](follow-up.md): work and outstanding decisions.
- [Canonical evidence](../../../notes/evidence/README.md): exact operator decisions, stored once for the workspace.
