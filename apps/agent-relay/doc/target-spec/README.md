# Product Target

**Utility:** indexes the agreed functional and technical target by domain.  
**Usage:** read before framing or reviewing a product capability or architectural constraint.

## Volumes

The [functional index](functional/README.md) covers behavior and constraints. The [technical index](technical/README.md) covers decided construction principles. Each domain links its two volumes.

## Reading boundaries

The target states intended product behavior, not implementation availability. It does not select a database, wire transport, client launch command or result protocol whose choice remains open.
