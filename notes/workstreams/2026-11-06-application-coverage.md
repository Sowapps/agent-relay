# Agent Relay application journey coverage

**Utility:** maps supported journeys to existing observations and the checks needed for a new release candidate.  
**Usage:** use the matrix to scope the next qualification GO and record candidate results separately.

## Scope and checkpoint

GO of 2026-11-06 covers inventory and prioritization. Source baseline is `468f465` on `main`. Existing observations are tied to their own builds and environments. This inventory reviews tracked scenarios and records without executing them. Objective creation was refused because an unrelated unfinished objective already exists.

P0 blocks candidate acceptance when it fails. P1 covers meaningful compatibility or usability risk after the critical gate. P2 is optional workload qualification or separate product work. A gap means the stated result still needs evidence on the target scope. Existing tests should be reused where they exercise the same boundary.
