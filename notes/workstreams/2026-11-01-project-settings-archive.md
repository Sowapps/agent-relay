## Design

Retain compatible configuration version1: Enabled=true means Active; false means Archived. Expose derived state to readers. Preserve history/membership/grants/credentials; no delete, workspace move or automatic session restart. General settings never selects a hidden last project. Its Projects tab lists all projects, supports opening their views and only lifecycle actions. Each project has a dedicated Settings tab; archived projects leave the left navigation but can be opened/read through the list.

Core project admission leases serialize same-project mutations and lifecycle preflight, leaving unrelated projects admissible. Full configuration writes acquire an exclusive admission barrier; this closes the old check-before-save race and prevents raw enabled changes bypassing lifecycle checks. State changes use fresh policy/expected-state checks, paged durable work/session verification, passive adapter inspection and atomic project-only persistence. Pending/running/approval/unknown work, uncertain/native-busy state or failed verification refuse archival; no agent is killed or task retried. Archived discovery/history remains readable within existing grants; new work, session mutations, inspection/import/recovery side effects are blocked. A new explicit project.manage grant allows scoped MCP lifecycle control; local authenticated administrator may use the same guarded use case. Existing grants are not expanded.
