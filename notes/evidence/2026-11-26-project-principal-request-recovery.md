# Project principal request recovery

**Source:** Florent, 26 November 2026, during the AP_D03 correction.

> L'agent principal du projet doit pouvoir TOUT faire, c'est ce qui a été demandé de base !! Aucun blocage n'est permis coté AR !!! Si une demande est bloquée, l'agent projet peut TOUT faire, il peut changer le statut, changer les infos, reprogrammer la demande, voir le résultat, l'annuler ou simplement la supprimer/désactiver. Il doit pouvoir se sortir de TOUTES les situations !!

**Settled:** The project principal can recover requests from its own project using inspection, correction, rescheduling, cancellation, disabling or deletion. See the functional Agent Session target, *Project principal control of requests*.
