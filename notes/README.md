# Project Notes

**Utility:** indexes historical records, observations and proposals.  
**Usage:** read when checking why a requirement exists or what still needs investigation.

## Records

- [Workstreams](workstreams/README.md): resumable scope and checkpoints for authorized work.

- [Workspace observations](observations/README.md): repository migrations and development-tool qualification.

- [Evidence](evidence/README.md): exact operator arbitrations cited by the documentation.
- [Observations](../apps/agent-relay/notes/observations/README.md): measured facts awaiting operator validation.
- [Proposals](../apps/agent-relay/notes/proposals/README.md): feasibility work and unarbitrated design candidates.
- [Follow-up](../apps/agent-relay/notes/follow-up.md): work performed and outstanding decisions.

## Organization

Evidence has one Markdown file per fact, named by its identifier. Observations are dated and retain their limitations. Proposals can change while under discussion; they are not the product contract.

There is no implementation release to describe in a changelog. Add a changelog when delivered product changes justify one; keep it separate from evidence and experiment reports.
